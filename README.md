# Hope-Medical-Donation-POE

First-year academic project — completed in 2024

A simple website created for a fictional medical donations organisation. The project was developed during my first year of studying Software Development to practise the fundamentals of web development.

## 🚀 Features

* **Home Page:** Introduction to the organisation
* **Donation Information:** Information about supporting the organisation
* **About & Contact:** Organisation and contact details
* **Responsive Design:** Basic mobile and desktop support

## 🛠️ Tech Stack

* **HTML5**
* **CSS3**
* **JavaScript**

## 📦 Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/hope-medical-donations.git
```

Open `index.html` in a web browser to view the website.
